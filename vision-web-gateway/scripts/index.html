What the zip must contain

my-dataset.zip
  classes.txt        one class name per line (line 1 = class 0)
  images/            .jpg .png ...
  labels/            YOLO .txt, same name as the image: class x y w h (0 to 1)

An image without a label file counts as background. Folder names inside the zip do not matter, file names must be unique.

Server load

%

Each running job may use that share of the CPU threads, RAM and GPU memory (GPU memory limits the batch size). Jobs start in order while the shares of the running jobs add up to 100% or less; the rest wait in the queue. Examples: 100 = one job at a time, 50 = two at a time, 33 = three at a time. A running job keeps the share it started with. The GPU itself is time-shared between running jobs, not capped.
